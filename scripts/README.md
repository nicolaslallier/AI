# Scripts

Petits scripts autonomes. Chaque script commence par un commentaire qui dit ce qu'il
fait, ses dépendances et un exemple d'appel. Un script Python sans dépendance lourde
peut déclarer les siennes en en-tête ([PEP 723](https://peps.python.org/pep-0723/))
pour se lancer avec `uv run script.py`.
